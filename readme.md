# 任务栏行情（bar_quote)

一个常驻 Windows 桌面的股票行情小组件，实时显示自选股的价格与涨跌幅，支持**桌面小组件**和**系统托盘图标**两种显示模式。

数据源：东方财富（优先 push 接口，全部失败时自动回退手机版网页兜底）。

---

## 一、启动方式

| 方式 | 说明 |
|------|------|
| 双击 `dist\QuoteBar.exe` | **推荐**。打包好的独立程序，无需 Python 环境 |
| 双击 `startup.bat` | 自动切到 UTF-8 代码页，控制台中文正常显示 |
| 命令行 | 在项目目录执行 `py -3 main.py`（或 `python main.py`） |

- 以 exe 运行时没有控制台窗口；配置文件是 **exe 同目录**的 `config.json`（首次运行自动释放默认配置）。
- 以 bat / 命令行运行时**不要关闭控制台窗口**，关闭窗口即结束程序。

---

## 二、功能特性

- **实时行情**：显示每只自选股的名称、现价、涨跌幅，按配置的间隔自动刷新。
- **可转债只显示价格**：可转债（沪市 `11xxxx`、深市 `12xxxx`）上行显示价格、不显示涨跌幅；分时弹窗标题同样省略涨跌幅。
- **两种显示模式**（可随时切换，切换结果会写回 `config.json`）：
  - `desktop` 桌面小组件：悬浮窗常驻桌面，可用鼠标拖动位置，位置自动保存。
  - `tray` 系统托盘图标：窗口隐藏，仅在系统托盘显示图标；鼠标悬停可看行情摘要。
- **名称自动获取**：股票名称从行情接口返回，取前两个字显示，无需手工配置。
- **分时图**：鼠标单击（或悬停）某只标的，在其上方弹出当日分时走势图。
- **涨绿跌红**：上涨显示红色、下跌显示绿色、平盘显示灰色，颜色可自定义。
- **自动配色**：可跟随系统任务栏的深/浅色主题自动调整背景与文字颜色。
- **行情查询窗口**：仅在规定时段内请求行情接口并打印日志，其余时间不发请求。

## 三、交互说明

| 操作 | 效果 |

| 右键单击托盘图标（`tray` 模式） | 弹出菜单 |

## 四、行情查询时段

程序只在各市场自身的交易时段内请求行情接口，其余时间沿用上一次取到的数据：

| 市场 | 交易时段（本地时间，周一至周五） |
|------|----------------------------------|
| A 股 | 9:30 – 11:30、13:00 – **15:00 收市** |
| 港股 | 9:30 – 12:00、13:00 – **16:00 收市** |

补充说明：

- 非交易时段（开盘前、午休、收市后、周末）**不发请求**，行情条保留最后一次（收盘）数据，日志标注「已收市」。
- 全部标的都休市时，检查间隔自动放宽到 60 秒，恢复交易后自动继续刷新。
- 程序可跨天常驻，无需重启；港股以东方财富 secid 的 `116.` 前缀识别，其余按 A 股处理。
- 仅按「周一至周五 + 固定时段」判断，**未覆盖法定节假日**（节假日期间表现为休市）。

## 五、配置文件 `config.json`

配置文件**每次刷新都会自动重新读取**，修改后无需重启程序即可生效（`mode` 与 `position` 也会被程序回写保存）。

### 完整示例

```json
{
  "symbols": [
    { "code": "688519.SH" },
    { "code": "301176.SZ" },
    { "code": "00700.HK" }
  ],
  "refresh_seconds": 3,
  "mode": "desktop",
  "position": {
    "x": 14,
    "y": 2102,
    "margin": 8,
    "gap_above_taskbar": 2,
    "embed_taskbar": false
  },
  "statusbar": {
    "pad_x": 10,
    "pad_y": 5,
    "gap": 16,
    "show_avg": true,
    "corner_radius": 8,
    "border_width": 1
  },
  "font": { "family": "Arial", "size": 11, "bold": false },
  "colors": {
    "background": "#1e1e1e",
    "name": "#aaaaaa",
    "price": "#eeeeee",
    "up": "#ff4d4f",
    "down": "#00c853",
    "flat": "#bbbbbb",
    "hover_bg": "#333333",
    "border": null,
    "auto_match_taskbar": true
  },
  "timeline": { "width": 280, "height": 130, "bg": "#1e1e1e", "border": "#444444" },
  "layout": { "price_decimals": 2 }
}
```

### `symbols` — 自选股列表

数组，每项一个对象，**只需配置 `code`**（`alias` 已废弃，名称由接口返回取前两字）。

```json
"symbols": [{ "code": "688519.SH" }, { "code": "301176.SZ" }]
```

代码书写规则：

| 写法 | 含义 |
|------|------|
| `600519.SH` | 沪市（上证） |
| `000001.SZ` | 深市（深证） |
| `430047.BJ` | 北交所（按深市前缀处理） |
| `00700.HK` | 港股（自动补成 5 位，如 `116.00700`） |
| `600519` | 无后缀，按首位判断：`5`/`6`/`9` 开头算沪市，其余算深市 |
| `0.301308` | 直接写东方财富 secid（`0.` 深、`1.` 沪、`116.` 港） |

> 美股（`.US`）暂不支持。

### `refresh_seconds` — 刷新间隔

查询窗口内的行情刷新间隔，**单位：秒**（示例为 3 秒）。窗口外该值不生效，仅启动时查一次。

### `mode` — 显示模式

| 值 | 说明 |
|----|------|
| `desktop` | 桌面小组件（默认）。悬浮窗常驻，可拖动 |
| `tray` | 系统托盘图标。窗口隐藏，点击托盘图标才显示浮窗 |

在程序内用右键菜单切换时，该值会被写回文件。

### `position` — 窗口位置

| 字段 | 说明 |
|------|------|
| `x` | 水平位置。可为关键字 `"right"`（贴右）、`"center"`（居中）、`"left"`（贴左），或数字：正数=距左边缘像素，负数=距右边缘像素（如 `-20`） |
| `y` | 垂直位置。数字：正数=距上边缘像素，负数=距下边缘像素；设为 `null` 则自动贴到任务栏上方 |
| `margin` | 使用关键字定位时距屏幕边缘的留白（像素） |
| `gap_above_taskbar` | 自动贴任务栏时，与任务栏之间保留的间隙（像素） |
| `embed_taskbar` | 是否尝试嵌入任务栏内部（AppBar）。Windows 11 上任务栏限制较多，**建议保持 `false`** |

> `desktop` 模式下拖动窗口后，`x` / `y` 会被自动改写为实际坐标并保存。

### `statusbar` — 行情条外观

| 字段 | 说明 |
|------|------|
| `pad_x` / `pad_y` | 内容区左右 / 上下内边距（像素） |
| `gap` | 各标的之间的水平间距（像素） |
| `corner_radius` | 圆角半径（像素），超过高度一半时自动取高度的一半 |
| `border_width` | 边框宽度（像素），`0` 为无边框 |
| `show_avg` | 预留字段，当前版本未使用 |

### `font` — 字体

| 字段 | 说明 |
|------|------|
| `family` | 字体名，如 `Arial`、`微软雅黑` |
| `size` | 字号 |
| `bold` | 是否加粗（`true` / `false`） |

### `colors` — 配色

所有颜色均为 `#RRGGBB` 格式。

| 字段 | 说明 |
|------|------|
| `background` | 行情条背景色 |
| `name` | 股票名称文字颜色 |
| `price` | 价格文字颜色 |
| `up` / `down` / `flat` | 上涨 / 下跌 / 平盘的涨跌幅颜色 |
| `hover_bg` | 鼠标悬停时该项的背景色 |
| `border` | 边框颜色；设为 `null` 表示不单独指定 |
| `auto_match_taskbar` | `true` 时跟随系统任务栏深浅主题自动覆盖背景与文字色（涨跌色保持不变） |

### `timeline` — 分时图弹窗

| 字段 | 说明 |
|------|------|
| `width` / `height` | 弹窗宽 / 高（像素） |
| `bg` | 背景色 |
| `border` | 边框颜色 |

### `layout` — 数值格式

| 字段 | 说明 |
|------|------|
| `price_decimals` | 价格保留的小数位数（如 `2`） |

## 六、常见问题

**Q：启动后看不到行情条？**
先看 `config.json` 的 `mode`。若为 `tray`，窗口是隐藏的，只在系统托盘显示图标——点击图标即可显示浮窗；想默认直接显示，把 `mode` 改成 `desktop`。

**Q：显示的名称不是我想要的？**
名称固定取行情接口返回名称的前两个字（如「旗天科技」→「旗天」），不可手工指定。若要调整，需改代码中的 `_short_name`（`main.py`）。

**Q：收盘后为什么数据不变？**
A 股 15:00、港股 16:00 收市后不再请求接口，显示的是最后一次（收盘）数据，属正常现象。

**Q：修改配置后没反应？**
配置每次刷新自动重读。若改的是 `symbols`，需要处于查询窗口内才会拉到新标的的数据；窗口外启动的程序可重启一次。

**Q：控制台出现 `libpng warning: iCCP` 警告？**
来自图形库的 PNG 处理，不影响功能，可忽略。

## 七、打包为独立 exe

只有打包时需要 PyInstaller，运行 exe 的电脑不需要 Python 环境：

```bat
py -3 -m pip install pyinstaller
py -3 -m PyInstaller --noconfirm --onefile --windowed --name QuoteBar --icon icon.ico --add-data "config.json;." main.py
```

产物：`dist\QuoteBar.exe`（单文件约 9 MB），复制到任意 Windows 10 / 11 电脑双击即用。

| 参数 | 作用 |
|------|------|
| `--onefile` | 打成单个 exe |
| `--windowed` | 无控制台窗口（程序内已处理无控制台时的日志输出） |
| `--icon icon.ico` | exe 图标（`icon.ico` 为项目自带图标文件） |
| `--add-data "config.json;."` | 把当前配置作为内置默认配置打包 |

说明：

- exe 首次运行会在**同目录释放 `config.json`**，之后以该文件为准，可直接编辑；程序目录在打包模式下取 exe 所在目录，配置可持久化保存。
- 重新打包前需先结束正在运行的 `QuoteBar.exe`，否则文件被占用会失败。
- 打包中间产物在 `build\`，`QuoteBar.spec` 是本次打包配置，之后也可用 `py -3 -m PyInstaller QuoteBar.spec` 重打包。
